Help improve the beta.

RetireWise is still being prepared for public launch. Feedback is useful, but please keep sensitive personal financial information out of public channels.

Product feedback and technical issues

RetireWise is currently in beta. The most practical contact route is the public GitHub issue tracker for the project.

Open the RetireWise GitHub Issues page →

Please protect your privacy.

GitHub issues are public. Do not include bank account numbers, PAN/Aadhaar numbers, passwords, tax returns, investment account screenshots or other sensitive personal financial information.

Business contact

A dedicated business email and domain-based contact address should be added before the site is promoted commercially. Until then, use the GitHub route only for non-sensitive product feedback.
