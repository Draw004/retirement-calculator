Privacy

The current planner is designed to work without an account.

This page describes how the current browser-based planner handles the information you enter. Carrowmont's site-wide Privacy Policy also applies.

Effective: 17 September 2026 · Applies to the Carrowmont Retirement Planner

Summary

The current Carrowmont Retirement Planner website does not require an account. Calculator inputs are processed in your browser. If you choose “Save plan on this device,” the saved plan is stored in your browser's local storage.

Information you enter into the calculator

The Carrowmont Retirement Planner does not intentionally transmit the financial assumptions you enter to a Carrowmont Retirement Planner database. The current static application has no account system and no server-side database for plan data.

Local storage

When you choose to save a plan, your browser stores a copy locally on that device. You can overwrite it by saving another plan. Clearing browser site data can remove it. Anyone with access to the same browser profile may be able to access locally stored information, so avoid saving sensitive information on a shared device.

Hosting and technical logs

The site is currently hosted using GitHub Pages. Like most web hosts, the hosting provider may process technical information needed to serve the site, such as IP address, request details and security logs, under its own policies. Carrowmont Retirement Planner does not control those provider-level logs.

Analytics and advertising

Analytics is not activated in this planner package by default. The code contains a disabled configuration placeholder so analytics can be added later. Before activating analytics, advertising or other third-party tracking, this policy should be reviewed and updated to describe the tools used and any consent or notice requirements that apply.

Contact and feedback

For privacy questions, use contact@carrowmont.com or the main Carrowmont contact page. Do not send account credentials, tax identifiers, passwords or other highly sensitive personal financial information.

Carrowmont site-wide Privacy Policy

The Retirement Planner is part of Carrowmont. For the broader website policy, see the Carrowmont Privacy Policy →.

Changes to this policy

This policy will be updated if Carrowmont Retirement Planner adds accounts, cloud storage, analytics, advertising, payments, newsletters or other data-processing features.
